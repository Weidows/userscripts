载入脚本：input-guard.html　｜　对照组（不载脚本、纯浏览器原生）：input-guard.html?mode=native

每组用例的判定：焦点在下面这些可编辑元素里时按 空格 / PageUp / PageDown / ↑ / ↓， 页面不应滚动，且按键应被该元素自己消费（输入框吃到字符 / 光标移动）。

1 · 单行输入框 #t-input

2 · 多行输入框 #t-area

3 · contenteditable #t-ce

可编辑块，空格应插入空格，↑↓ 应在行间移动光标

4 · Shadow DOM 内的 input #t-shadow-input

自定义元素的内部输入框：事件 target 会被重定向成宿主，靠 e.target 判断可编辑性会漏。

5 · Shadow DOM 内的 contenteditable #t-shadow-ce

6 · 嵌套 Shadow DOM 内的 input #t-shadow-nested

7 · 隐藏 textarea 伪装的编辑器（CodeMirror 类）#t-fake-editor

假编辑器：真焦点在一个透明 textarea 上

8 · Shadow DOM 内的滚动框 #t-inner-scroller

鼠标滚轮停在这个内层滚动框里时，应该滚它自己，页面不动（原生手感）。

9 · Shadow DOM 内的锚点链接 #t-shadow-link

点它应触发卷轴动画跳到「contenteditable」那节 —— 链接在 shadow root 里，靠 e.target 找不到。
